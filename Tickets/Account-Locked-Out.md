Ticket 1 — User Account Locked Out

# Issue
User reported being unable to access their company account because the account was locked.

# User Impact
The user was unable to sign in and access company resources.

# Troubleshooting Performed

Verified the user's identity.
Confirmed the user was receiving a lockout message.
Checked the account status.
Investigated possible causes of the lockout.
Verified the account could be unlocked.
Had the user attempt to sign in again.

# Resolution
The user's account was unlocked and the user was able to sign in successfully.

# Ticket Status
*Resolved**
