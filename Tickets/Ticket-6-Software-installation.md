# Ticket 6 — Software Installation Request

## Issue
User requested installation of 7-Zip to extract project files from a ZIP archive.

## User Impact
The user needed to extract project files but was unsure whether 7-Zip was an approved company application.

## Troubleshooting Performed

Confirmed which files the user needed to extract.
Asked when the user needed access to the files.
Verified whether 7-Zip was an approved company application.
Considered whether an existing approved Windows application could perform the required task.
Recommended using Windows File Explorer's built-in extraction functionality.
Used:
  `Right-click → Extract All`

## Findings

The user did not necessarily need third-party software because Windows File Explorer could extract the ZIP archive using built-in functionality.

## Resolution

Used Windows File Explorer's built-in **Extract All** feature instead of installing unapproved third-party software.
