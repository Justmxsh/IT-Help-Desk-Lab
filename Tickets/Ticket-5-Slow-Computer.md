# Ticket 5 — Slow Computer

## Issue
User reported that their computer was running unusually slowly.

## User Impact
The user experienced reduced system performance while trying to complete normal work.

## Troubleshooting Performed

Checked Task Manager for CPU, memory, and disk utilization.
Investigated which processes were using system resources.
Asked whether the user had recently downloaded or added files.
Checked Windows Search indexing activity.
Allowed indexing to complete.
Rechecked disk utilization after indexing finished.

## Findings

High disk usage was associated with Windows Search indexing newly added files.

## Resolution

Allowed Windows Search indexing to complete and verified that disk usage decreased afterward.

## Ticket Status
**Resolved**
