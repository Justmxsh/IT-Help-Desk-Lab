# IT Help Desk Troubleshooting Lab

Hands-on IT Help Desk lab simulating real-world Tier 1 support scenarios using Jira Service This is a hands-on IT Help Desk troubleshooting lab documenting Tier 1 support scenarios, troubleshooting methodology, network diagnostics, ticket documentation, and escalation procedures.
 and Windows troubleshooting tools.

## Overview

This project documents eight simulated IT support tickets covering common Tier 1 Help Desk issues.

The lab focuses on troubleshooting methodology, user communication, technical diagnostics, ticket documentation, and appropriate escalation.

## Skills Demonstrated

  Windows troubleshooting
  Network troubleshooting
  DNS and TCP/IP fundamentals
  VPN troubleshooting
  Printer troubleshooting
  User account troubleshooting
  File and shared-drive troubleshooting
  Software installation and security awareness
  Phishing investigation
  Ticket documentation
  Incident escalation

## Tools & Technologies

  Jira Service Management
  Windows 11
  Cisco Secure Client
  Windows Task Manager
  Windows Services
  Device Manager
  Windows Security
  Command Prompt
